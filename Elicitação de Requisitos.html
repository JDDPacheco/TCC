Relatório de Elicitação de Requisitos


Introdução

O objetivo deste relatório é documentar os requisitos do sistema de gestão de uma dada drogaria de pequeno porte, identificando os problemas atuais e as necessidades do cliente.


Problemática

A drogaria foi criada a pouco tempo, tem menos de 1 ano e dispõe de baixo orçamento. Atualmente possui um sistema informatizado baseado em Google Sheet com algumas automatizações usando Google Scripts, porém este sistema não atende todas as necessidades da proprietária.
O estabelecimento é alvo de fiscalizações da Vigilância Sanitária e precisa apresentar os dados de venda de medicamento de controle especial acurados, porém não dispões destes.

Pontos Negativos Atuais:

  • O único sistema informatizado existente é muito limitado e não tem interface amigável para os usuários, que acabam preferindo não utilizá-lo;
  • A gestão é realizada sem auxílio de relatórios com dados acurados;
  • Todos os registros são feitos em um caderno físico ou ficam apenas na memória da proprietária;
  • As operações financeiras de venda não são registradas;
  • O relatório apresentado à Vigilância Sanitária não é eletrônico, o que pode gerar incosistencias e/ou causar más interpretações que podem levar a multa ou outros meios de sansão administrativa.

Pontos Positivos Atuais:

  • Existem os recursos de hardware necessários disponíveis para uso;
  • A proprietária tem uma boa base de conhecimento do negócio.

Limitações

As seguintes limitações devem ser consideradas no desenvolvimento do sistema:

  • Não há verba para uso de serviços externos pagos;
  • O sistema não pode ter usabilidade complexa pois será utilizado por pessoas que não tiveram uma base em informática na sua formação profissional;

Stakeholders

Os seguintes stakeholders estão envolvidos no sistema:

  • Gestor(a);
  • Farmacêutico(a);
  • Operador(a) de Caixa;

Objetivos

Os objetivos do sistema são:

  • Gerar, armazenar e emitir relatório de dados de vendas (principalmente de medicamento de controle especial);
  • Ser amigável e de usabilidade intuitiva e simples suficiente para os usuários terem interesse em utilizá-lo;
  • Emitir relatórios de interesses gerenciais;
  • Fazer a gestão completa do estoque de produtos;
  • Controlar o processo de venda de forma que o cliente sinta segurança no atendimento;

Conclusão

Este relatório apresenta os requisitos do sistema de gestão de uma drogaria, identificando os problemas atuais e as necessidades dos usuários. O sistema deve ser desenvolvido considerando as limitações e requisitos funcionais e não funcionais apresentados.
